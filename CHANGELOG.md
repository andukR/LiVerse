# История изменений LiVerse

Нынешний проект продолжает нумерацию выпусков LiVerse `1.0.0` и `1.0.1`,
которые были подготовлены в репозитории `liveverse-public-release`.

## [1.2.1] — 2026-09-01

### Изменено

- окно LiVerse показывает номер версии, а основные кнопки остаются читаемыми
  при системном оформлении Windows с низкой контрастностью;
- проверщик установщика автоматически использует находящиеся рядом установщик
  и файл его контрольной суммы SHA-256.

### Исправлено

- восстановлен запуск распознавания после подключения HoLyrics;
- при недостающих разрешениях API выводится их точный список;
- если HoLyrics отклоняет обычную команду показа стиха, LiVerse использует
  резервный показ с темой текущей презентации плана проповеди;
- остановка распознавания больше не зависает при отсутствии звука с микрофона;
- сборка Windows не принимает оставшийся от предыдущего запуска установщик за
  новый и корректно работает с пустым виртуальным CD-ROM.

## [1.2.0] — 2026-08-25

### Добавлено

- графический интерфейс без обязательной консоли: состояние, настройки,
  диагностика, помощь и безопасный экспорт журналов;
- фиксированный QR-код подключения телефона и телефонный полноэкранный режим;
- дистанционный телефонный пульт для следующего и предыдущего слайда песен;
- установщик Windows, воспроизводимая сборка в офлайн-VM и бинарный обновлятор
  через проверенные ресурсы GitHub Releases;
- новая потоковая модель Sherpa/Vosk 0.54 и база поиска цитат по тексту в
  составе Windows-дистрибутива.

### Изменено

- обновление упакованной Windows-версии больше не требует Git, Python и `pip`;
- индикатор микрофона и окончательно распознанные строки доступны в GUI;
- телефонный пульт остаётся дополнительным средством управления, а не
  обязательной частью автоматического показа.

### Исправлено

- штатное завершение Windows-движка теперь успевает показать итоги сеанса;
- кнопки итогового окна остаются видимыми при небольшом экране и увеличенном
  масштабе Windows;
- устаревшее подтверждение последнего стиха не прерывает следующий слайд
  длинного отрывка;
- исправлены регрессии диапазонов и коротких цитат после контекстного отрывка;
- секретные поля скрываются при создании архива диагностических журналов.

## [1.1.0] — 2026-08-09

### Добавлено

- автономное распознавание русской речи через Vosk;
- web-пульт и локальное всплывающее окно подтверждения оператора;
- полуавтоматический режим с оценкой риска ложного срабатывания;
- автоматическое распознавание и переключение строк плана проповеди Holyrics;
- распознавание цитаты по произнесённому тексту стиха;
- контекстные диапазоны и автоматическое перелистывание длинных отрывков;
- сохранение настроек запуска и штатные установщики для Linux и Windows;
- проверка обновлений при обычном запуске LiVerse.

### Изменено

- основной автономный распознаватель заменён с faster-whisper на более лёгкий
  Vosk, пригодный для церковного компьютера без мощной видеокарты;
- библейские слайды используют тему текущей презентации плана проповеди;
- уверенные результаты показываются автоматически, а сомнительные передаются
  оператору для подтверждения.

### Исправлено

- ложные срабатывания на обычной речи и искажённых Vosk названиях книг;
- промежуточное мелькание рабочего стола при переходе между планом и стихом;
- потеря контекста после длинного диапазона и ручного перелистывания Holyrics;
- размещение всплывающих окон на границе двух мониторов.

## [1.0.1] — 2026-06-19

- исправлено распознавание ASR-варианта названия книги Колоссянам;
- исправлена сборка ссылки, разделённой между соседними фрагментами речи.

## [1.0.0] — 2026-06-19

- первый стабильный выпуск LiVerse с распознаванием библейских ссылок,
  контекстной памятью, операторским управлением и выводом в Holyrics.
