# История изменений LiVerse

Нынешний проект продолжает нумерацию выпусков LiVerse `1.0.0` и `1.0.1`,
которые были подготовлены в репозитории `liveverse-public-release`.

## [1.2.11] — 2026-09-30

### Добавлено и улучшено

- регулярные выражения парсера компилируются заранее; на проверенных фразах
  разбор заметно ускорился без изменения результатов;
- окно настроек переразложено по двум колонкам, список разрешений Holyrics
  сгруппирован для более удобного поиска.

### Исправлено

- оформление пустой текстовой презентации сохраняется на время показа серии
  подтверждаемых ссылок; временная тема быстрой презентации Holyrics больше не
  приводит к отказу показа списка;
- выбор и сохранение имени темы Holyrics удалены: LV использует актуальные
  настройки Holyrics, а устаревшее значение `HOLYRICS_THEME` больше не
  применяется;
- добавлена ASR-форма «юан» для Иоанна в компактных списках ссылок.

Подробности проверки производительности приведены в
`docs/PERFORMANCE_TEST_20260927.md`.

## [1.2.10] — 2026-09-25

### Исправлено

- продолжение списка ссылок по аудиометкам больше не завершается из-за
  медленной обработки компьютером;
- распознаются разделённые и усечённые ASR-формы адресов, включая «восьм ой»
  и «десят стих», а также восстанавливается граница в «стихмарка»;
- диапазон стихов без восстановленного номера главы больше не превращается
  ошибочно в ссылку на первую главу;
- числа перед названием следующей книги не присваиваются этой книге, если
  соответствующий кандидат книги уже стоит перед числами;
- восстановлена запись результатов очереди подтверждений в журнал запуска.

### Добавлено

- необязательные замеры времени этапов обработки и загрузки CPU LiVerse
  в отдельный файл `performance.jsonl`.

## [1.2.7] — 2026-09-18

### Добавлено

- потоковый УПС стал штатным способом перелистывания длинного диапазона в
  режиме «один стих на слайд»: он сопоставляет поток распознанных слов с
  текущим и следующим стихом, сохраняя ручное управление оператора;
- в настройках LiVerse добавлен переключатель потокового УПС и безопасный
  возврат к прежнему алгоритму перелистывания.

### Исправлено

- после окончания длинного диапазона LiVerse надёжнее восстанавливает слайд
  плана проповеди и не показывает повторно последний стих поверх него;
- при запуске длинного диапазона учтена короткая задержка Holyrics, из-за
  которой прежний слайд плана мог ошибочно восприниматься как ручной возврат;
- расширены контекстные правила распознавания адресов и диапазонов, включая
  распространённые искажения Sherpa и повторное объявление ссылки.
- проверка снимка исходников для Windows-сборки корректно читает UTF-8 имена
  документов, включая кириллические.

## [1.2.5] — 2026-09-09

### Исправлено

- разговорные вводные вроде «один очень хороший стих» больше не превращаются
  в ложную ссылку `1:1` и не приостанавливают поиск по тексту;
- при рискованно распознанном адресе LiVerse продолжает сопоставлять читаемый
  текст с Библией: текст может расширить или исправить первоначальный слайд,
  но уже показанный стих повторно не выводится.

## [1.2.3] — 2026-09-03

### Изменено

- словарь названий книг Библии полностью хранится внутри LiVerse и больше не
  зависит от файлов соседнего проекта;
- диагностический сценарий Windows VM умеет проверять быстрый показ стиха и
  безопасно возвращать текстовую презентацию на выбранный слайд.

### Исправлено

- неполные адреса стихов после длинного отрывка больше не подменяют текущую
  книгу случайным вариантом из накопленного речевого контекста;
- перед показом стиха LiVerse заново получает текущий слайд плана проповеди,
  использует его индивидуальный фон и после показа возвращается на тот же
  слайд;
- журнал HoLyrics содержит достаточно сведений о фактической команде, теме и
  ответе API для разбора ошибок на другом компьютере.

## [1.2.2] — 2026-09-01

### Исправлено

- установщик Windows надёжно останавливает и удаляет старый
  `LiVerseEngine.exe`, не допуская смешивания файлов разных версий;
- перед показом длинного библейского отрывка сохраняется текущий слайд плана
  проповеди, чтобы восстановить его после распознавания последнего стиха.

## [1.2.1] — 2026-09-01

### Изменено

- окно LiVerse показывает номер версии, а основные кнопки остаются читаемыми
  при системном оформлении Windows с низкой контрастностью;
- проверщик установщика автоматически использует находящиеся рядом установщик
  и файл его контрольной суммы SHA-256.

### Исправлено

- восстановлен запуск распознавания после подключения HoLyrics;
- при недостающих разрешениях API выводится их точный список;
- если HoLyrics отклоняет обычную команду показа стиха, LiVerse использует
  резервный показ с темой текущей презентации плана проповеди;
- остановка распознавания больше не зависает при отсутствии звука с микрофона;
- сборка Windows не принимает оставшийся от предыдущего запуска установщик за
  новый и корректно работает с пустым виртуальным CD-ROM.

## [1.2.0] — 2026-08-25

### Добавлено

- графический интерфейс без обязательной консоли: состояние, настройки,
  диагностика, помощь и безопасный экспорт журналов;
- фиксированный QR-код подключения телефона и телефонный полноэкранный режим;
- дистанционный телефонный пульт для следующего и предыдущего слайда песен;
- установщик Windows, воспроизводимая сборка в офлайн-VM и бинарный обновлятор
  через проверенные ресурсы GitHub Releases;
- новая потоковая модель Sherpa/Vosk 0.54 и база поиска цитат по тексту в
  составе Windows-дистрибутива.

### Изменено

- обновление упакованной Windows-версии больше не требует Git, Python и `pip`;
- индикатор микрофона и окончательно распознанные строки доступны в GUI;
- телефонный пульт остаётся дополнительным средством управления, а не
  обязательной частью автоматического показа.

### Исправлено

- штатное завершение Windows-движка теперь успевает показать итоги сеанса;
- кнопки итогового окна остаются видимыми при небольшом экране и увеличенном
  масштабе Windows;
- устаревшее подтверждение последнего стиха не прерывает следующий слайд
  длинного отрывка;
- исправлены регрессии диапазонов и коротких цитат после контекстного отрывка;
- секретные поля скрываются при создании архива диагностических журналов.

## [1.1.0] — 2026-08-09

### Добавлено

- автономное распознавание русской речи через Vosk;
- web-пульт и локальное всплывающее окно подтверждения оператора;
- полуавтоматический режим с оценкой риска ложного срабатывания;
- автоматическое распознавание и переключение строк плана проповеди Holyrics;
- распознавание цитаты по произнесённому тексту стиха;
- контекстные диапазоны и автоматическое перелистывание длинных отрывков;
- сохранение настроек запуска и штатные установщики для Linux и Windows;
- проверка обновлений при обычном запуске LiVerse.

### Изменено

- основной автономный распознаватель заменён с faster-whisper на более лёгкий
  Vosk, пригодный для церковного компьютера без мощной видеокарты;
- библейские слайды используют тему текущей презентации плана проповеди;
- уверенные результаты показываются автоматически, а сомнительные передаются
  оператору для подтверждения.

### Исправлено

- ложные срабатывания на обычной речи и искажённых Vosk названиях книг;
- промежуточное мелькание рабочего стола при переходе между планом и стихом;
- потеря контекста после длинного диапазона и ручного перелистывания Holyrics;
- размещение всплывающих окон на границе двух мониторов.

## [1.0.1] — 2026-06-19

- исправлено распознавание ASR-варианта названия книги Колоссянам;
- исправлена сборка ссылки, разделённой между соседними фрагментами речи.

## [1.0.0] — 2026-06-19

- первый стабильный выпуск LiVerse с распознаванием библейских ссылок,
  контекстной памятью, операторским управлением и выводом в Holyrics.
