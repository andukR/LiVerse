# Release Notes LiVerse 1.2.8

`Release Notes` (заметки к выпуску) фиксируют изменения версии, необходимые
разрешения внешних программ и порядок проверки после установки.

## Что изменилось

- улучшено распознавание русских ASR-искажений названий библейских книг и
  порядковых числительных, в том числе в составных и неполных объявлениях;
- уточнено различие между одиночной ссылкой, диапазоном и списком ссылок;
- исправлено восстановление диапазонов, когда номер главы уже был сказан в
  предыдущем фрагменте речи, а границы стихов — в следующем;
- в просмотре replay показывается общее число неразмеченных случаев во всех
  сохранённых пачках;
- усилены регрессионные проверки парсера, текстового поиска и сценариев
  разметки УПС;
- сохранены потоковый УПС, режим «один стих на слайд» и ручное управление
  оператором из версии 1.2.7.

Полное описание проверенных правил находится в
`docs/SMART_SLIDE_USER_GUIDE.md`.

## Разрешения Holyrics API Server

Новых разрешений в версии 1.2.8 нет. Должны сохраняться разрешения,
необходимые для показа, перелистывания и восстановления плана проповеди:

- `GetAPIServerInfo`, `GetBibleSettings`, `GetCurrentPresentation`,
  `GetCurrentQuickPresentation`;
- `ActionNext`, `ActionPrevious`, `ActionGoToIndex`;
- `CloseCurrentQuickPresentation`, `CloseCurrentPresentation`;
- `SetBibleSettings`, `ShowQuickPresentation`, `ShowText`, `ShowVerse`.

Для выбранной темы Holyrics также нужен `GetThemes`. Для сохранения фона
быстрой презентации должны оставаться включены `GetBackgrounds` и
`GetCurrentBackground`.

## Проверка на церковном компьютере

1. Установить 1.2.8 поверх 1.2.7.
2. Проверить в Holyrics разрешения и сохранённый token.
3. Проверить распознавание нескольких адресов с ASR-искажениями и диапазонами.
4. Проверить потоковый УПС на диапазоне «один стих на слайд» и ручное
   подтверждение клавишей Enter.
5. Проверить возврат презентации плана проповеди после окончания диапазона.
