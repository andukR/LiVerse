# LiVerse 1.2.14

## Перед началом работы

Установщик можно запускать прямо с флэшки поверх 1.2.13. Закройте LiVerse
перед установкой. Сохранённые настройки остаются, включая тестовое время показа.
Галочка завершения установки теперь называется «Открыть LiVerse и проверить настройки».

При каждом запуске графического LV открывается вкладка «Настройки» с сообщением
«Проверьте настройки перед запуском!». Проверьте время показа цитаты, микрофон
и режим. Только затем нажмите «Сохранить и запустить». До запуска окно не
скрывается в трей. Консольный запуск сохраняет прежний порядок.

LV проверяет связь и разрешения Holyrics до запуска распознавания. При ошибке
показывает сообщение и остаётся в настройках. Если параметры изменены во время
проверки, повторите запуск. Зелёное «Работает» означает запуск распознавания,
но не подтверждает изображение на проекторе.

Новых команд API по сравнению с исправленной 1.2.13 нет. Теперь для запуска
из графического окна требуется успешная проверка GetTokenInfo и списка
разрешений. После перехода со старой сборки особенно проверьте GetF10,
GetWallpaperSettings, ShowLyrics, SetF8, SetF9, GetThemes и GetCurrentBackground.
Полный актуальный список: кнопка «Разрешения HoLyrics»; включать в
Holyrics → Settings → API Server → Manage permissions → Local.
Проверку разрешений на церковном компьютере выполняет оператор после установки.

## Исправления

- Возврат к предыдущей песне или плану полностью выполняется в фоне. После
  принятой команды LV ждёт подтверждения переключения до 10 секунд; неполный
  ответ не считается успешным возвратом или ручным выбором оператора.
- Старый обработчик возврата не очищает новую цитату. Новая цитата отменяет
  ещё не начавшийся возврат. Во время уже выполняющегося возврата новый показ
  отклоняется: повторите его после переключения. Отложенного показа нет.
- Завершённый диапазон перестаёт управлять слайдами сразу при постановке
  возврата на выполнение. Ручное переключение и F10 прекращают старую проверку.
  Если возврат не подтверждён, журнал фиксирует ошибку; проверьте экран вручную.
- Локальное окно подтверждения показывает библейский текст, когда цитата
  найдена по произнесённому тексту, и крупный адрес, когда произнесён адрес.
  У длинного текста есть прокрутка; адрес остаётся под текстом для справки.
- Анализатор журналов учитывает незавершённые проверки и ошибки возврата.
- Импорт журналов выполняется из проекта: `bash tools/import_liverse_logs.sh`.
  Импортер переносит файлы независимо от имени, проверяет ZIP и пропускает
  повреждённые архивы с сообщением, продолжая обработку остальных.

В исходниках также сохранён отдельный инструмент извлечения блока пения из
записи (`tools/extract_worship_audio.py`); он не меняет живое распознавание LV.

## Короткая проверка на церковном компьютере

1. Откройте LV. Убедитесь, что открыты настройки, распознавание ещё не работает,
   а сохранённое время показа видно. Для этой проверки поставьте 5 секунд;
   после теста верните время для богослужения.
2. Откройте план в Holyrics, выберите поиск адресов и текста с подтверждением,
   нажмите «Сохранить и запустить». Устраните сообщения о разрешениях, если есть.
3. Скажите: «Евангелие от Иоанна, третья глава, шестнадцатый стих».
   Окно должно показать адрес. Подтвердите; проверьте цитату и возврат к плану.
4. После возврата прочитайте без адреса: «Ибо так возлюбил Бог мир, что отдал
   Сына Своего Единородного, дабы всякий верующий в Него не погиб, но имел
   жизнь вечную». Если LV предложит подтверждение, окно должно показать
   библейский текст и адрес под ним. Проверьте фактический показ и возврат.
5. Остановите распознавание, верните рабочее время показа и запустите снова.

Автоматические проверки не заменяют проверку с настоящим Holyrics и общим
экраном. Эта проверка на церковном компьютере перед публикацией не выполнялась.
