# Release Notes LiVerse 1.2.9

## Что изменилось

- улучшено восстановление адресов по контексту длинного диапазона: полный
  явно произнесённый адрес из другой книги или главы остаётся самостоятельной
  цитатой;
- расширена обработка русских ASR-искажений названий библейских книг,
  порядковых числительных, сокращённых форм и диапазонов между главами;
- компактные списки ссылок теперь принимают несколько неуверенно распознанных
  названий книг, если каждый адрес имеет связную структуру; такой список в
  полуавтоматическом режиме всегда требует подтверждения оператора;
- в живом режиме список можно продолжать новыми ссылками в течение двух секунд;
  подтверждения обрабатываются очередью, а распознавание речи во время ответа
  оператора не останавливается;
- улучшены показ глав и списков ссылок через Holyrics, включая временный показ
  и возврат к сохранённому слайду плана проповеди;
- расширены инструменты replay-эмуляции и разметки сохранённых запусков.

Подтверждённые примеры и ограничения описаны в
`docs/SMART_SLIDE_USER_GUIDE.md` и `README.md`.

## Разрешения Holyrics API Server

Новых разрешений Holyrics API в изменениях 1.2.9 не добавлено. Сохраняются
разрешения, необходимые для показа стихов и списков, управления быстрой
презентацией и возврата к плану проповеди. После установки всё равно следует
проверить подключение LiVerse к Holyrics и сохранённый набор разрешений на
церковном компьютере.

## Проверка на церковном компьютере

1. Установить 1.2.9 поверх 1.2.8 и проверить сохранение настроек.
2. Проверить одиночные адреса и диапазоны с ASR-искажениями.
3. Проверить список из нескольких ссылок с неуверенно распознанными названиями
   книг: каждая ссылка должна требовать подтверждения.
4. Во время подтверждения одной ссылки произнести следующую и проверить очередь;
   после паузы более двух секунд проверить завершение сбора списка.
5. Проверить временный показ списка в Holyrics и возврат к прежнему слайду плана.
6. Проверить показ главы и работу умного перелистывателя на длинном отрывке.
