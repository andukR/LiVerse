# Release Notes LiVerse 1.2.7

`Release Notes` (заметки к выпуску) фиксируют изменения версии, необходимые
разрешения внешних программ и порядок проверки после установки.

## Что изменилось

- потоковый УПС стал обычным режимом для длинных диапазонов при настройках
  «один стих на слайд», Sherpa и текстовом поиске;
- слайд следующего стиха появляется по последовательному совпадению речи с
  концом текущего и началом следующего стиха; ручное переключение оператора
  остаётся главным и очищает старое речевое совпадение;
- в настройках LiVerse добавлена галочка «Потоковый УПС для чтения стих за
  стихом (рекомендуется)». Если её снять и перезапустить распознавание,
  включается прежний УПС;
- после окончания чтения диапазона LiVerse возвращает презентацию плана
  проповеди и не должен повторно показывать последний стих.
- сборка Windows корректно проверяет документы с кириллическими именами в
  снимке исходного кода.

Полное описание поведения, ограничений и отличий live-режима от replay находится
в `docs/SMART_SLIDE_USER_GUIDE.md`.

## Разрешения Holyrics API Server

Новых разрешений в версии 1.2.7 нет. Сохраняются разрешения, нужные LiVerse для
показа, перелистывания и восстановления плана проповеди:

- `GetAPIServerInfo`, `GetBibleSettings`, `GetCurrentPresentation`,
  `GetCurrentQuickPresentation`;
- `ActionNext`, `ActionPrevious`, `ActionGoToIndex`;
- `CloseCurrentQuickPresentation`, `CloseCurrentPresentation`;
- `SetBibleSettings`, `ShowQuickPresentation`, `ShowText`, `ShowVerse`.

Если в настройке LiVerse выбрана тема Holyrics, token также должен иметь
`GetThemes`. Для надёжного сохранения фона быстрой презентации оставьте
включёнными ранее добавленные `GetBackgrounds` и `GetCurrentBackground`.

## Проверка на церковном компьютере

1. Установить обновление поверх LiVerse 1.2.6 обычным обновлятором.
2. В `Holyrics → Settings → API Server → Manage permissions` проверить
   перечисленные разрешения и сохранённый token.
3. Открыть LiVerse → «Настройки», выбрать «один стих на слайд» и убедиться, что
   галочка потокового УПС включена.
4. На коротком объявленном диапазоне проверить: первый стих появляется после
   начала чтения, последующие сменяются по одному, а после последнего стиха
   возвращается план проповеди.
5. Для проверки аварийного возврата снять галочку, сохранить настройки и
   перезапустить распознавание: LiVerse должен использовать прежний УПС.
