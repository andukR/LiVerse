# LiVerse 1.2.15

## Исправленная сборка от 24 октября 2026

- В Windows-дистрибутив включены данные словарей `pymorphy2_dicts` и
  `natasha`, необходимые для `words2numsrus`. В первоначальной сборке код
  библиотек присутствовал, но без этих данных преобразователь чисел не
  загружался. Из-за этого «с первого по двенадцатой» могло превратиться в
  ошибочный диапазон 1–2 вместо 1–12.
- Женское окончание конечного числительного в явном диапазоне «с … по …»
  обрабатывается и без дополнительного преобразователя чисел. Правило
  относится к живому режиму и повторному разбору сохранённой речи.
- Проверка ресурсов готового EXE и установленной программы теперь напрямую
  проверяет работу `words2numsrus`, включая «двенадцатой» → 12. Неполная
  упаковка словарей останавливает проверку сборки.
- Исправленный установщик сохраняет номер 1.2.15. Его можно установить
  поверх первоначальной 1.2.15; автоматизация проверяет замену исполняемого
  файла и сохранение пользовательских данных.

## Что изменилось

- При чтении большого библейского отрывка оператор может вернуть прежнюю
  презентацию кнопкой «Вернуть план», не останавливая распознавание. Если
  пастор сначала объявил большой диапазон, а затем назвал меньший диапазон
  внутри него, потоковый УПС учитывает границу этого чтения и возвращает
  прежний экран после его окончания. Если меньший диапазон не назван, LV
  может распознать переход от чтения к объяснению по окончанию стиха и нескольким
  последующим фразам. Это работает в живом режиме Sherpa при показе по одному
  стиху и настроенной теме цитат. Кнопка и автоматический возврат не перезапускают
  микрофон; прежний библейский контекст сохраняется.
- Окно уточнения главы показывает исходную распознанную фразу. Например,
  оператор видит «…четвёртогла пятнадцатый стих…» и может понять, какую главу
  просит указать LV.
- Известные слитные формы числительного с началом слова «глава» распознаются
  как номер главы: «четвёртогла» → «четвёртая глава». Правило работает для
  известных порядковых числительных и их составных форм, не заменяя обычные
  слова без явного маркера главы.
- После успешного выбора и показа адреса чтение того же стиха больше не
  создаёт повторное предложение, в том числе после паузы. Отклонённый адрес
  не блокирует последующий поиск правильной ссылки по тексту.
- Итоги сеанса сохраняются в журнале до показа итогового окна. В графическом
  интерфейсе их можно снова открыть во вкладке «Журналы» кнопкой «Итоги
  сеанса»; там же доступно действие WhatsApp.
- Крестик главного окна завершает LiVerse; для сворачивания в трей есть кнопка
  «Скрыть». В настройках графического интерфейса потоковый УПС для чтения по
  одному стиху включён как штатное поведение.
- Обновлён значок приложения.

## Разрешения Holyrics

Новых разрешений API Server по сравнению с 1.2.14 нет. После установки
проверьте настройки кнопкой «Разрешения HoLyrics». Программа должна получить
успешный ответ проверки token и текущий список разрешений; физический экран
Holyrics всё равно нужно проверить оператору.

## Проверка и ограничения

Сборка 1.2.15 автоматически запускает полный набор регрессионных проверок на
Linux и Windows, сборку приложения и установщика, чистую установку и обновление
поверх предыдущего установщика с проверкой сохранения пользовательских настроек
(для исправленной сборки — поверх первоначальной 1.2.15). Результаты
фиксируются в журнале сборки после фактического завершения этих шагов.

Автоматические проверки не заменяют проверку на церковном компьютере с настоящим
Holyrics, микрофоном и общим экраном. Эвристика возврата после объяснения
использует окончание стиха и форму последующей речи; она не понимает смысл
проповеди и требует операторского наблюдения. Подробные условия и ограничения
описаны в `docs/SMART_SLIDE_USER_GUIDE.md`.
