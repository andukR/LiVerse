# Release Notes LiVerse 1.2.13

## Перевыпуск

Исправленная сборка 1.2.13 заменяет первоначальную сборку от 6 октября 2026.
Номер версии сохранён по запросу пользователя. Уже установленная 1.2.13
не получает предложение обновления по номеру версии: для неё запустите
новый установщик вручную, например с флешки.

## Что изменилось

- Когда на общем экране виден текст песни, LV не заменяет его цитатой,
  списком или диапазоном, в том числе после подтверждения оператором.
  Состояние проверяется непосредственно перед отправкой команды.
  Неизвестное содержимое слайда песни также блокирует показ. Отложенного
  автоматического показа заблокированной цитаты нет.
- На пустом фоне цитаты сохраняют видимый фон с настройками текста из
  `For_LiVerse`; поверх плана или приветственной текстовой презентации
  используется оформление текущего слайда. Для отсутствующей презентации
  или неподдерживаемых базовых обоев используется запасная тема.
- Через заданное время LV возвращает исходную песню или план на сохранённый
  слайд и проверяет результат. Чёрный экран F10 и последующее ручное
  переключение оператора сохраняются. Переходы по старому плану не заменяют
  активную песню. Создайте в Holyrics одну запасную тему `For_LiVerse`.
- Бинарный Windows-обновлятор скачивает установщик частями, продолжает
  загрузку после обрыва и отмены, показывает прогресс, скорость и оставшееся
  время, предлагает повторить при неустойчивой связи. Этапы и ошибки пишутся
  в `logs/updates.jsonl` и включаются в экспорт журналов. Размер и SHA-256
  проверяются до запуска установщика. Изменение относится к будущим
  обновлениям после установки этой сборки; прежний обновлятор сам не меняется
  до её установки.

- Длинным считается диапазон от трёх стихов. В режиме показа по одному стиху
  `Иаков 5:1-3` получает три слайда УПС без таймера временной цитаты. Вложенный
  отрывок не сужает общий контекст `Иаков 5:1-6`. Неполное «с четвёртого по
  восьмой стих» восстанавливается по этому контексту: пересечение допускает
  выход не более чем на два стиха за конец в той же главе. Правила относятся
  к живой работе и replay; два явно названных стиха остаются временной цитатой.

- Окно уточнения недостающей главы, подтверждение перехода по плану и
  предупреждение о неверном адресе больше не останавливают обработку звука.
  Окна обслуживаются общей очередью по одному; оператор по-прежнему сам
  вводит главу или отменяет запрос. Переходы плана и эти ветви также попадают
  в `performance.jsonl`.
- При показе временного стиха или списка LiVerse не повторно использует
  сохранённый ID темы, если активен другой экран, а сам ID отсутствует в
  каталоге Holyrics. Для обычного показа применяется доступная тема Bible-
  модуля или выбор Holyrics по умолчанию. При отказе нового показа сохраняется
  таймер возврата предыдущего успешного слайда.
- Одиночное порядковое числительное в продолжаемом чтении, например «третье»,
  само по себе не считается адресом; слово «стих» по-прежнему позволяет
  распознать его как номер стиха.
- Исправлены несколько подтверждённых ошибок разбора по replay-записям:
  «Титу» вместо «Откровения», «два» вместо слова «глава» в адресе Римлянам
  14:12 при совпадении полного текста стиха, и ложный адрес Иаков 1:1,
  возникавший из обычного упоминания послания без номера главы и стиха.
- В replay-инструмент добавлен выбор всех неразмеченных случаев текущей пачки
  и отдельная команда для скачивания последней воскресной записи без запуска
  эмуляции.

## Разрешения Holyrics API Server

Включите в столбце Local ранее используемые разрешения из
[README](../README.md#holyrics-api-server), а также новые для перевыпуска:
`GetF10`, `GetWallpaperSettings`, `ShowLyrics`, `SetF8`, `SetF9`.
Для получения оформления даже без плана нужны `GetThemes`, `GetBackgrounds`,
`GetCurrentTheme`, `GetCurrentBackground`. Запуск LV проверяет доступность
разрешений. Пользователь подтвердил правильную работу исходников на ноутбуке;
после установки на церковный компьютер проверьте его token и общий экран.

## Проверка на церковном компьютере

Для короткой проверки именно исправлений этого выпуска во вкладке «Состояние»
нажмите «Тест последнего релиза». Общий прогон УПС, списки и длинное чтение
оставлены в кнопке «Общий тест». В короткий тест включён только новый случай
трёх стихов, поскольку правило запуска УПС для него изменено в этом выпуске.
В коротком сценарии действуйте по инструкциям в квадратных скобках:

1. Во время окна уточнения «Иаков, шестой стих» не отвечайте примерно 10 секунд,
   продолжая читать обычный текст. Убедитесь, что новые фразы продолжают
   обрабатываться, очередь не накапливается, а после `Esc` стих не показывается.
2. Покажите текст песни и произнесите Иоанна 3:16: LV не должен менять экран.
   Затем оставьте от песни пустой фон, снова произнесите адрес и подтвердите
   его: фон должен сохраниться, текст оформляется по `For_LiVerse`; через
   5 секунд должен вернуться прежний пустой слайд. Откройте план и повторите
   цитату: оформление плана и прежний слайд должны сохраниться.
3. Упоминание послания Иакова без адреса не должно вызвать показ. Затем
   прочитайте Иаков 5:1–3 в режиме по одному стиху: таймер в 5 секунд не должен
   закрыть отрывок; по завершении чтения должен вернуться план.
   Остановите распознавание, откройте «Журналы» → «Проверить сеанс» и сохраните
   отчёт. Короткая проверка может дать недостаточно данных для вывода о
   производительности или устойчивости на всё богослужение.

Кнопка «Общий тест» сохраняет прежний расширенный сценарий: обычная речь,
список из четырёх ссылок, длинный отрывок с УПС и другие общие проверки.

Автоматические тесты и replay не заменяют проверку настоящего микрофона,
Holyrics и проектора на целевом компьютере.
