# Release Notes LiVerse 1.2.11

## Что изменилось

- Ускорен разбор адресов Библии за счёт предварительной компиляции устойчивых
  шаблонов. В контрольных замерах Windows VM фразы разбирались примерно в
  10–14 раз быстрее; методика и ограничения описаны в
  `docs/PERFORMANCE_TEST_20260927.md`.
- Исправлен показ постепенно подтверждаемого списка в пустой текстовой
  презентации Holyrics. Исходное оформление снимается один раз и повторно
  применяется для следующих временных слайдов, даже если Holyrics назначил
  предыдущему временному слайду собственную тему.
- LiVerse больше не предлагает выбрать и не сохраняет имя темы Holyrics.
  Оформление остаётся под управлением Holyrics; старое `HOLYRICS_THEME` из
  `.env` игнорируется и удаляется при следующем сохранении настроек.
- Добавлена ASR-форма «юан» для Иоанна в компактных списках ссылок.
- Настройки переразложены по двум колонкам, а разрешения Holyrics
  сгруппированы для удобного поиска.

## Разрешения Holyrics API Server

Новых разрешений не добавлено. Для режима плана проповеди по-прежнему нужны
`GetThemes`, `GetBackgrounds`, `GetCurrentTheme` и `GetCurrentBackground`, а
также разрешения показа и восстановления презентации, перечисленные в разделе
Holyrics README. Для обычного вывода выбор темы в LiVerse больше не нужен.

## Проверка перед использованием

1. Установить 1.2.11 поверх 1.2.10 и проверить сохранение настроек и работу
   Holyrics API.
2. Запустить пустую текстовую презентацию и произнести несколько адресов,
   подтверждая каждый. Проверить, что список обновляется на дополнительном
   экране с исходным фоном и после показа возвращается пустая презентация.
3. В настройках Holyrics заменить тему и убедиться, что LiVerse не использует
   старое имя темы.
4. Проверить компактный список адресов Иоанна с ASR-формой «юан».
5. Если важна скорость на старом компьютере, сравнить время разбора по
   инструкции и данным `docs/PERFORMANCE_TEST_20260927.md`; замеры в этом файле
   получены на тестовой Windows VM и не гарантируют такую же кратность на
   другом оборудовании.
