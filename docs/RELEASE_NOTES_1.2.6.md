# Release Notes LiVerse 1.2.6

`Release Notes` (заметки к выпуску) — обязательный документ для каждой версии.
В нём перечисляются изменения, новые разрешения внешних служб и действия,
которые нужно выполнить после установки. Это помогает не забыть настройку,
без которой поведение программы может быть непредсказуемым.

## Что изменилось

- улучшено распознавание библейских адресов и длинных диапазонов;
- добавлены операторские подсказки и браузерная эмуляция УПС;
- добавлена работа LiVerse с темами Holyrics при запуске.

## Обязательные разрешения Holyrics API Server

Для функций, добавленных в 1.2.6, в token Holyrics должны быть включены:

- `GetThemes` — чтение списка тем;
- `GetBackgrounds` — чтение списка фонов;
- `GetCurrentBackground` — чтение текущего фона для восстановления оформления
  (этот вызов также делает текущая версия LiVerse).

После установки нужно открыть `Holyrics → Settings → API Server → Manage
permissions`, включить эти разрешения, сохранить token и проверить запуск
LiVerse на церковном компьютере. Если `GetCurrentBackground` запрещён, это
фиксируется в журнале как HTTP 401, а восстановление исходного фона надёжно
гарантировать нельзя.

## Правило следующих выпусков

До публикации версии обязательно создать `docs/RELEASE_NOTES_<версия>.md`,
добавить туда все новые разрешения Holyrics API и выполнить перечисленные в
документе действия на целевой машине. Пункт Release Notes должен быть отмечен
в общем release checklist до создания установщика.
